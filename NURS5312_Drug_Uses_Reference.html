NURS 5312 · Psychopharmacology · Drug Uses

What each drug is used for

A plain drug-to-use list grouped by therapeutic category — no mechanisms, just the disorders each agent treats. Many drugs cross several categories (e.g., quetiapine spans schizophrenia, bipolar, and depression).

Items marked (off-label) are widely used but not FDA-approved for that use.
